# 🛍️ LuxeCart E-Commerce Storefront

A fully functional, modern e-commerce web application built using the `FakeStoreAPI` product catalog, featuring client-side state management and a seamless user shopping experience.

---

## ✨ Features

* **Dynamic Catalog Rendering:** Renders product cards complete with high-resolution imagery, pricing, category badges, and star rating scores.
* **Category & Keyword Filtering:** Filter products dynamically by category (Electronics, Jewelry, Men's Clothing, Women's Clothing) or perform real-time keyword searches.
* **Slide-Out Cart Drawer:** Interactive slide-out cart with quantity increment/decrement buttons, item removal, and a live navbar badge counter.
* **Automated Calculations:** Real-time calculation of subtotal, estimated tax (8%), shipping costs, and grand total.
* **Checkout Flow:** Interactive modal displaying order confirmation and generated reference numbers upon checkout.
* **Local Persistence:** Retains cart items across browser refreshes using `localStorage`.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Grid & Flexbox), JavaScript (ES6+)
* **Data Source:** `FakeStoreAPI` JSON Dataset
* **Icons:** FontAwesome
* **Storage:** Browser `localStorage` API
